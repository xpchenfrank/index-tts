================================================================================
                        快速开始（3步上手）
================================================================================

⚠️  重要提示：本项目使用 UV 环境管理，请确保在 UV 环境中运行！

第一步：确保 UV 环境已配置
--------------------------
  如果还没有创建环境，请先执行：
    pip install uv
    uv sync

第二步：安装 API 依赖（在 UV 环境中）
------------------------------------
  # 激活环境
  Windows:  .venv\Scripts\activate
  Linux/Mac: source .venv/bin/activate
  
  # 安装依赖
  uv pip install fastapi uvicorn requests

第三步：启动服务
----------------
  方式1 (推荐)：
    Windows:  双击运行 start_api.bat
    Linux/Mac: 运行 ./start_api.sh
  
  方式2 (手动)：
    uv run python api.py
  
  方式3 (已激活环境)：
    先激活环境，然后 python api.py

  看到 "Uvicorn running on http://0.0.0.0:8000" 表示启动成功

第四步：测试服务
----------------
  方法1: uv run python test_api.py    (命令行测试)
  方法2: 用浏览器打开 test_page.html  (网页测试)
  方法3: uv run python api_client_example.py (示例代码)

================================================================================
                        API 接口说明
================================================================================

基础接口：
  GET  http://localhost:8000/          - 查看 API 信息
  GET  http://localhost:8000/health    - 健康检查
  GET  http://localhost:8000/info      - 获取模型信息

核心接口：
  POST http://localhost:8000/tts       - 文本转语音（返回音频流）
  POST http://localhost:8000/tts_json  - 文本转语音（返回JSON）

API 文档：
  http://localhost:8000/docs           - 交互式文档（推荐）

================================================================================
                        使用示例
================================================================================

Python 调用示例：
-----------------
import requests

response = requests.post(
    "http://localhost:8000/tts",
    json={"text": "你好，世界！"}
)

with open("output.wav", "wb") as f:
    f.write(response.content)


cURL 调用示例：
--------------
curl -X POST "http://localhost:8000/tts" \
  -H "Content-Type: application/json" \
  -d "{\"text\":\"你好，这是测试\"}" \
  --output output.wav

================================================================================
                        性能优化建议
================================================================================

如果想要更快的生成速度，可以编辑 api.py：

找到这部分代码：
  tts_model = IndexTTS2(
      model_dir=model_dir,
      cfg_path=cfg_path,
      use_fp16=False,        # 改为 True 启用半精度
      use_cuda_kernel=False  # 改为 True 启用 CUDA 加速
  )

改为：
  tts_model = IndexTTS2(
      model_dir=model_dir,
      cfg_path=cfg_path,
      use_fp16=True,         # ← 这里
      use_cuda_kernel=True   # ← 这里
  )

注意：需要 NVIDIA GPU 支持

================================================================================

Q: 启动时提示找不到模型？
A: 确保 checkpoints 目录下有完整的模型文件

A: 参考 api_client_example.py 中的示例代码

Q: 可以同时处理多个请求吗？
A: 可以，但注意 GPU 内存限制

Q: 如何更换端口？
A: 编辑 api.py 最后一行，修改 port 参数

================================================================================
                        项目集成示例
================================================================================

在你的 Python 项目中：
---------------------
# 1. 启动 IndexTTS API 服务
#    python api.py

# 2. 在你的项目代码中调用
import requests

def text_to_speech(text: str, output_file: str):
    """文本转语音"""
    response = requests.post(
        "http://localhost:8000/tts",
        json={"text": text}
    )
    
    if response.status_code == 200:
        with open(output_file, "wb") as f:
            f.write(response.content)
        return True
    return False

# 使用
text_to_speech("你好，世界！", "hello.wav")
