✅ 已为你完成 API 服务封装！

================================================================================
                     立即开始（3步）
================================================================================

第1步：检查环境 ✓
-------------------
在 UV 环境中运行环境检查：

  uv run python check_environment.py

如果有问题，按照提示修复。

第2步：启动 API 服务 ✓
-----------------------
Windows:
  双击运行 start_api.bat
  
  或在命令行：
  uv run python api.py

Linux/Mac:
  ./start_api.sh
  
  或在命令行：
  uv run python api.py

看到 "Uvicorn running on http://0.0.0.0:8000" 表示成功！

第3步：测试服务 ✓
------------------
方式1 - 自动测试：
  uv run python test_api.py

方式2 - 网页测试：
  用浏览器打开 test_page.html

方式3 - 查看 API 文档：
  浏览器访问 http://localhost:8000/docs

================================================================================
                     在你的项目中使用
================================================================================

其他项目调用 API 不需要 UV 环境，只要能发 HTTP 请求即可！

Python 示例：
-------------
import requests

response = requests.post(
    "http://localhost:8000/tts",
    json={"text": "你好，世界！"}
)

with open("output.wav", "wb") as f:
    f.write(response.content)

cURL 示例：
-----------
curl -X POST "http://localhost:8000/tts" \
  -H "Content-Type: application/json" \
  -d "{\"text\":\"你好，这是测试\"}" \
  --output output.wav

================================================================================
                     常见问题
================================================================================

Q1: 为什么必须用 UV 环境？
A:  IndexTTS 项目使用 UV 管理依赖，需要特定版本的 PyTorch 等包。
    详细说明请看：关于环境和服务的说明.md

Q2: IndexTTS 服务不是要单独启动吗？
A:  不需要！IndexTTS 是库不是服务。api.py 启动时会自动加载模型。
    详细说明请看：关于环境和服务的说明.md

Q3: 其他项目如何调用？
A:  发送 HTTP POST 请求到 http://localhost:8000/tts 即可。
    不需要 UV 环境，任何语言都可以调用。
    示例请看：api_client_example.py

Q4: 生成速度慢怎么办？
A:  编辑 api.py，设置 use_fp16=True 和 use_cuda_kernel=True
    需要 NVIDIA GPU 支持。

Q5: 如何更换参考音频？
A:  将音频文件放入 sampleAudios 目录，重启 API 服务即可。

Q6: 遇到错误怎么办？
A:  1. 运行 check_environment.py 检查环境
    2. 查看 API 启动日志
    3. 阅读"关于环境和服务的说明.md"
